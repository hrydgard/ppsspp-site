> I discovered an inbuilt cheat in the PSP game of "Fired Up". It hashes internal names and does some evaluations
> Long story short, in "Fired Up", if you set your name to: QQQQQQQQ (uppercase letter Q x 8), it enables godmode, infinite ammo, and unlocks the entire story.
> Longer story: to enable godmode, the sum of ASCII characters in the name must be 648.
